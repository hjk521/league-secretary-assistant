# 团支书智能助手

League Secretary Assistant —— 把团委、组织部发下来的长通知，拆成团支书当天就能执行的东西：谁要做什么、什么时候交、哪些表要填、哪些环节本班不做、材料怎么命名、怎么留痕。

不是把通知复述一遍。核心是回答四个问题：

- 这次通知发给谁，每个收件人真正要做什么？
- 团支委内部谁负责哪一步，哪些事其实不用派人？
- 哪些要求本班适用、哪些不适用、哪些附件根本没写？
- 上次的命名、格式、流程能不能直接复用？

## 三条硬规则

1. **先查附件，再问人。** 会议要不要开、能不能线上开，一律先从附件原文找答案，附件确实没写才来问你。能从附件读出来的问题不该占你时间。
2. **提交一律接龙，不派人催收。** 团员交完材料、投完票，自己在群里用接龙管家接龙；团支书看接龙名单判断谁没交，只私聊缺交的人，不在群里点名。
3. **命名照上一份被接收过的文件，不照通知模板。** 通知里的“20××级××专业×班”是占位符，照抄必错。

## 安装

把整个目录复制到你所用工具的 skills 目录下，目录名用 `league-secretary-assistant`，关键是里面要有 `SKILL.md`。

| 工具 | skills 目录 |
|---|---|
| Claude Code | `~/.claude/skills/` |
| Codex CLI | `~/.codex/skills/` |
| WorkBuddy | `~/.workbuddy/skills/` |

复制完成后不用手填模板。第一次对话时它会有一次初始化，用 5 个问题把班级档案问清楚并写进 `本班记忆.md`：

1. 学院、年级、专业、班级全称怎么写，上一份被接收过的文件叫什么；
2. 班级总人数、团员人数；
3. 团支委构成；
4. 班会和团课一般线上还是线下、多长时间、要不要签到；
5. 有没有用过接龙管家或问卷星。

五问答完就建档，之后只核对会变的部分。不想被问，也可以自己复制 `本班记忆模板.md` 填好。

## 说话方式

这个 skill 对输出语言有硬要求，也是它跟直接问 AI 的区别之一：

- 说人话，一句话能说清的不写三句，先结论后理由。
- 不自造词汇。必须用简称时，首次出现就把中文名、英文原名、单位、含义一次讲清。
- 不乱用比喻。“牛鼻子”“抓手”“闭环”“赋能”这类词不出现。
- 不照搬附件长难句。附件原文只用来核对依据，引用时标出处，然后翻译成人话。

## 目录

```
SKILL.md          主体：第 1—9 节通用规则
本班记忆模板.md    空白模板，复制成 本班记忆.md 后填写
examples/
  示例-团员年度评议.md   一次完整跑通的输出长什么样（已脱敏）
```

## 它能处理什么

团课、团费缴纳、入党推优、班团一体化、五四评优、入团积极分子发展、转专业档案交接、团支书会议、团员年度评议、团籍注册、专题组织生活会。

## 输出长什么样

固定七段：结论、需要你确认、内部安排、可直接发送的通知、类型专属内容（表格字段／会议流程／视频检索方案）、历史材料复用、留痕清单。

`examples/示例-团员年度评议.md` 是一份完整样例，可以直接照着改。

## 隐私

`本班记忆.md` 里会有真实姓名、班级人数、党员与积极分子构成。

- 不要提交到公开仓库，不要转发到公开群。
- 给别人用的时候，只发 `本班记忆模板.md`，别发填好的版本。
- 需要多人协作时，把填好的版本放私有仓库，并在 `.gitignore` 里排除。

## 说明

这个 skill 里的比例、到会人数、优秀名额等都要**用脚本算**，不要心算：向下取整之后还要回验一次，取整后的比例是否真的没超上限。

所有输出都只是草案。发送、提交、公示之前，仍然要你自己核一遍附件原文。
